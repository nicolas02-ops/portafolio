# Portafolio - Nicolas Anacona

Portafolio personal para presentar proyectos academicos y practicos en Python,
C++ y Qt.

## Proyectos destacados

- **Tetris en C++**: juego de consola con tablero dinamico, piezas, rotacion,
  movimiento y limpieza de lineas.
- **Gestor de torneo en C++/Qt**: aplicacion de consola para administrar
  equipos, jugadores, partidos, grupos y estadisticas desde archivos CSV.
- **Sistema de notas en Python**: carga de estudiantes y notas desde CSV,
  calculo de promedios, consultas y prediccion de matriculados.
- **Triqui en Python**: juego de tres en raya contra computadora con validacion
  de entradas y estrategia basica.

## Tecnologias

Python, C++, Qt Console, manejo de archivos CSV, programacion orientada a
objetos, logica de juegos y Git.

## Ver el portafolio

Abre `index.html` en el navegador.

## Preparar para GitHub

```bash
git init
git add .
git commit -m "Agregar portafolio inicial"
git branch -M main
```

Luego crea un repositorio en GitHub y conecta el remoto:

```bash
git remote add origin https://github.com/tu-usuario/portafolio.git
git push -u origin main
```

Antes de publicar, actualiza en `index.html` tu correo, GitHub y LinkedIn.
